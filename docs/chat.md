# Чаты и официальные объявления

Раздел объединяет переписки с продавцами, поддержку, группы и каналы. Источник данных и правил доступа — модуль `apps/api/src/chat`. Web и админ-панель используют общий `ApiClient` и типы `packages/types/src/chat.ts`; Flutter-приложение — свой типизированный репозиторий, работающий с тем же HTTP-контрактом.

## Официальные каналы

| Категория | Название | Назначение |
| --- | --- | --- |
| `NEWS` | Новости сервиса | Изменения в работе и общие объявления |
| `PROMOTIONS` | Акции | Предложения, условия и сроки скидок |
| `SECURITY` | Безопасность | Общие советы по защите аккаунта и предупреждения о мошенничестве |

Это общедоступные каналы сервиса, а не персональные уведомления. Не публикуйте здесь данные клиентов, заказы, коды подтверждения и сведения о входах в конкретный аккаунт. Канал безопасности сам по себе не обнаруживает подозрительные входы и не заменяет защиту авторизации.

Администратор или менеджер открывает «Чаты», выбирает один из трёх каналов и создаёт его, если он ещё не существует. Категория уникальна: повторное создание возвращает существующий канал. Редактор показывает историю и предварительный просмотр обычного текста; публикация происходит отдельной кнопкой. Пользователь находит канал в каталоге и подписывается добровольно. Управление участниками вручную в официальных каналах не предусмотрено.

Сервер проверяет роль сотрудника при публикации. Обычный путь отправки сообщений не разрешает писать в официальный канал, даже его создателю. Название пользовательской группы не даёт ей официальный статус: клиент использует поле `officialCategory`.

## Контракт API

Все пути ниже относительны к `/api`. Требуется авторизованная сессия; административные методы доступны только ролям `ADMIN` и `MANAGER`.

| Метод | Путь | Данные / результат |
| --- | --- | --- |
| POST | `/chat/admin/official-channels` | `{ category: "NEWS" \| "PROMOTIONS" \| "SECURITY" }`, возвращает канал |
| GET | `/chat/admin/official-channels/:id/messages` | `{ room, messages }`, последние 200 сообщений |
| POST | `/chat/admin/official-channels/:id/messages` | `{ body: string }`, возвращает опубликованное сообщение |

Сообщение содержит от 1 до 2000 символов. Интерфейс удаляет пробелы по краям и запрещает отправку пустого текста. История ограничена последними 200 сообщениями; это не полный архив с пагинацией. При неоднозначном сетевом сбое редактор сохраняет текст и предлагает сначала обновить историю: автоматическая повторная отправка могла бы создать дубликат.

## Остальные разговоры

Переписки с продавцами и поддержка сохраняют отдельные потоки сообщений. Между пользователями общение пока организовано через группы, не через поиск чужих аккаунтов и личные сообщения. Приглашение по ссылке позволяет человеку самому решить, вступать ли. Каналы магазинов принадлежат продавцам и отличаются от официальных каналов сервиса. Администратор продолжает управлять обычными группами через существующие инструменты.

Не следует обещать пользователям сквозное шифрование, push-доставку, SMS или доставку через Telegram на основании наличия чата: эти свойства требуют отдельных механизмов и проверки. Публикация в канале означает доступность сообщения внутри сервиса, а не подтверждение прочтения каждым подписчиком.

## Проверка перед выпуском

Проверить создание каждой категории и повторное создание без дублей; публикацию от администратора и менеджера; отказ обычному пользователю; подписку, чтение и отписку; невозможность написать в официальный канал через обычный маршрут; сохранность обычных групп и переписок. Проверить пустой текст, предел 2000 символов, сетевую ошибку и обновление истории без потери черновика. Применить миграцию поля категории до запуска новой версии API.
